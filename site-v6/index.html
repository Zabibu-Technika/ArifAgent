01 / What's coming

Not a point release. A new surface.

Zabibu Arif 6 is a rebuild of the workspace around the way the work actually happens: spoken, spatial, professional, and local.

01 / Speech

Speech detection

Talk to the workspace. Local speech detection turns intent into actions without shipping your audio to a server.

02 / Canvas

Canvas-based interface

A spatial canvas for documents, code, plans, and outputs. Arrange the work the way you think, not in a single chat column.

03 / Tools

Professional tools built in

Code, growth, bizops, writing, finance, research. First-party tools with one permission model and one proof trail.

04 / Native

Offline / native build

The build that finally runs without a browser or a network. Native, local, and yours—on the machine you already have.

05 / More

And more

A new memory layer, faster routing, and a cleaner proof trail. The rest lands with the build.

06 / The core

Same verified core

Every new surface inherits Weaver's verification, decision memory, reversibility, and account discipline.
