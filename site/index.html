02 / The axes

Not a chatbot with plugins. A product with engines.

01 / Code

Elite software engineering

Read, edit, search, run, verify. The mono-axis core is narrow on purpose; Arif does not dilute it. Every change is gated before it happens.

02 / Growth

Analytics, queue, publishing

Summarise a CSV, draft a post, queue it locally. Publishing is a separate egress action that refuses without an adapter—and writes its compensation first.

03 / Bizops

Invoices and CRM, in cents

Totals are integer cents with local dates, not UTC. CRM payloads land in a local outbox; nothing is sent by a draft.

The engine

Arif Agent

The agent is the architecture.

Arif Agent is not a fork of Weaver. It inherits core/ through a hash-checking sync daemon, so safety defaults cannot drift between products. Add an axis without touching the loop, the gate, or the receipt format.

  • One core, inherited. The sync daemon hashes every file and refuses to overwrite a local edit.
  • Same proof, every axis. A growth action and a code change produce the same kind of receipt.
  • Same undo, every axis. File changes use checkpoints; external actions use a two-phase journal.
  • Engines are contracts. The next product is a folder, not a rewrite.

03 / Identity

Multiple sign-ins. One chosen account. No silent switches.

GitHub↗

Every identity, listed

Reads gh auth status --json hosts. Lists every authenticated account, switches with gh auth switch, and remembers the choice per workspace. Pushes and pull requests use the account you picked.

Vercel↗

Every team, explicit

Reads vercel teams ls and vercel whoami. Switches with vercel switch. Deploys go to the scope you chose.

Switching is a modal: the account, the consequence, and the way back are on screen before anything changes.

Quickstart

Code, growth, and business ops in one terminal.

git clone https://github.com/Zabibu-Technika/ZabibuWeaver.git
git clone https://github.com/Zabibu-Technika/ArifAgent.git
cd ArifAgent
npm run sync
npm install
npm start

Arif Agent inherits Weaver's core on sync. Node 24+. No account required until you choose to connect one.
