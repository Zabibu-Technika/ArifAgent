The product↗

Zabibu Arif

A multi-axis workspace for people who want code, growth, and business operations handled by one agent, with a reviewable record of what changed.

The engine

Arif Agent

An open, local-first agent that inherits Weaver's verified core. It is the thing you install, point at a workspace, and give accounts to.

This is the one site for both names. Fikra is the model family; Weaver is the coding core.

The axes

Not a chatbot with plugins. A product with engines.

Coding

Elite software engineering

Inherits Weaver's coding engine: read, edit, search, run, verify. The mono-axis core is narrow on purpose; Arif does not dilute it.

Growth

Analytics, queue, publishing

Summarise a CSV export, draft a post, queue it locally. Publishing is a separate egress action that refuses without an adapter — and writes its compensation before it posts.

Bizops

Invoices and CRM, in cents

Invoice totals are computed in integer cents with local dates, not UTC. CRM payloads land in a local outbox; nothing is sent by a draft.

Built to adapt

Zabibu Arif is one expression of it. The architecture is the product.

01Inheritance

One core, inherited

Arif Agent does not fork Weaver. It inherits core/ through a sync daemon that hashes every file and refuses to overwrite a local edit. Safety defaults cannot drift between products.

02Contracts

Engines are contracts

An axis declares its tools, capabilities, and provenance. Add a new engine without touching the loop, the gate, or the receipt format. Zabibu Arif is the first expression; the next one is a folder.

03Proof

Same proof, every axis

A growth action and a code change produce the same kind of receipt: what ran, what passed, what was skipped, and whether the turn authored its own judge.

04Reversible

Same undo, every axis

File changes use checkpoints. External actions use a two-phase journal: plan, commit, compensate. An action with no compensation is recorded as irreversible, not hidden.

Identity, explicit

Multiple sign-ins. One chosen account. No silent switches.

GitHub

Every identity, listed

Reads gh auth status --json hosts. Lists every authenticated account, switches with gh auth switch, and remembers the choice per workspace. Pushes and pull requests use the account you picked.

Vercel

Every team, explicit

Reads vercel teams ls (JSON first, table fallback) plus vercel whoami. Switches with vercel switch <scope>. Deploys go to the scope you chose.

Switching is a modal: the account, the consequence, and the way back are on screen before anything changes. A CLI that needs different flags can declare a manifest in .weaver/integrations/.

Quickstart

Code, growth, and business ops in one terminal.

git clone https://github.com/Zabibu-Technika/ZabibuWeaver.git
git clone https://github.com/Zabibu-Technika/ArifAgent.git
cd ArifAgent
npm run sync
npm install
npm start

Inherits Weaver's core on sync. Node 24+. No account required until you choose to connect one.
